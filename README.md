# 坦克大战 · Battle City

一个使用纯 HTML + CSS + JavaScript（Canvas）编写的经典坦克大战游戏，无需任何依赖，打开即玩。

## 🎮 玩法

- 控制己方坦克，消灭场上所有敌军坦克，守护基地（红色老鹰）。
- 敌军会优先向基地和玩家进攻。
- 每关 20 名敌人，全部消灭后进入下一关，难度逐级提升。

## ⌨️ 操作

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` / `W A S D` | 移动坦克 |
| `Space` / `J` | 开炮 |
| `P` | 暂停 / 继续 |

## 🧱 地图元素

- **砖墙**：可被子弹击毁
- **钢铁**：无法摧毁
- **水面**：坦克无法通行，子弹可以飞过
- **树丛**：遮挡视野，坦克可通行
- **基地**：被击中则游戏结束

## ▶️ 运行

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器托管。
